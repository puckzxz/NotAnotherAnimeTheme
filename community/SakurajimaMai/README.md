# Sakurajima Mai

A calm, lavender Sakurajima Mai theme made by [takeisan24](https://github.com/takeisan24), built on NotAnotherAnimeTheme.

![Sakurajima Mai theme preview](https://raw.githubusercontent.com/takeisan24/Sakurajima-Mai-Discord-Theme/refs/heads/master/image/preview/main.jpg)

- Animated Mai wallpaper behind dark glass, with solid popouts, menus and modals
- "Lavender Dusk" palette drawn from the wallpaper, applied through Discord's own design tokens (menus, popouts, Stage, Onboarding, Shop...)
- Lavender for unread and selected, rose-mauve for mentions, small hover interactions, bunny logo in the title bar
- Keeps Nitro profile colors and plugin colors (BetterFolders, ShikiCodeblocks, RoleColorEverywhere) by default, with switches to use the Mai palette instead
- Honors Discord's Reduced Motion, High Contrast and Saturation settings

Works with Vencord / Vesktop and BetterDiscord. `SakurajimaMai.theme.css` in this folder loads the latest version of the theme, so fixes arrive automatically.

Full documentation, customization variables and screenshots: [Sakurajima-Mai-Discord-Theme](https://github.com/takeisan24/Sakurajima-Mai-Discord-Theme).
